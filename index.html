ABOUT

私たちについて

中央大学 電気工学研究部は、後楽園キャンパスを拠点に活動する理工系サークル。 電子工作・ドローン・アマチュア無線・ソフトウェア、 4つの領域を持つ班を自由に渡り歩きながら、「自分で作る」をひたすら楽しむ場所です。

学部・学科は問いません。ハードウェアもソフトウェアも、 入ってから触れば大丈夫。先輩と部室のパーツ箱が、あなたの学びをバックアップします。

4つの班
01 / 04

無線班

RADIO DIVISION

アマチュア無線 JA1YGX を運用。短波のDXからV/UHFのコンテスト、 自作アンテナ・自作トランシーバまで、電波で世界とつながる班。

  • HF / V / UHF
  • DX
  • Antenna
  • SDR
02 / 04

ドローン班

DRONE DIVISION

機体の組立・チューニングから、FPV飛行、空撮、制御プログラムまで。 モノを飛ばすロマンを、工学の力で突き詰める班。

  • FPV
  • Racing
  • Aerial
  • Flight Ctrl
03 / 04

マイコン・ロボット班

MCU / ROBOT DIVISION

Arduino / ESP32 / STM32 / Raspberry Pi。 センサとモーターとはんだごてを駆使して、 考えたものをそのまま動く形にする班。

  • Arduino
  • ESP32
  • PCB
  • Robotics
04 / 04

ソフトウェア班

SOFTWARE DIVISION

Web、ゲーム、機械学習、CTF、競プロ、ツール制作。 各々が書きたいものを書き、見せ合い、磨く。 コードで遊ぶ、コードで作る班。

  • Web
  • Game
  • ML / AI
  • CTF
03

ACTIVITIES

主な活動
  1. SPRING

    新歓 / 部室解放

    新入生向けの体験会・部室開放。はんだごて、ドローン、無線機、PC — 全部まとめて触れる週間。

  2. SUMMER

    合宿 / 各班制作

    フィールドデーコンテスト、夏のモノ作り集中期間。各班それぞれの作品を持ち寄って磨き込む。

  3. AUTUMN

    白門祭 出展

    学園祭で作品展示とデモ。無線体験、ドローンシミュレータ、ロボット、自作ゲームを一堂に。

  4. WINTER

    成果発表 / LT大会

    1年の成果を発表するLT会。班をまたいだコラボ企画もここから生まれることが多い。
